This workflow demonstrates how to work with documents using the <SiteName /> CLI. It covers listing collections, creating a new one with metadata, uploading content and files, and running search.

## Step 1: List Collections

Check what collections already exist for your project:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} document collection list`}
  </code>
</pre>

## Step 2: Create Collection

Create a new document collection with metadata:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} document collection create "Marketing Documents" --metadata '{"department": "Marketing", "type": "documents"}'`}
  </code>
</pre>

## Step 3: Add Documents

Add a document directly with content:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} document doc add <collection-id> "This document outlines the marketing strategy for Q1." --metadata '{"title": "Q1 Marketing Strategy"}'`}
  </code>
</pre>

Upload a file to the same collection:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} document doc upload-file <collection-id> ./marketing_report.pdf --type pdf`}
  </code>
</pre>

## Step 4: Search

Search the collection using a query:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} document doc search <collection-id> "Marketing Strategy"`}
  </code>
</pre>
