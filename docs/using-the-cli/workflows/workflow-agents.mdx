This workflow walks through the full lifecycle of deploying an agent using the <SiteName /> CLI. It includes environment setup, agent creation, deployment, and cleanup.

## Step 1: Project Setup

Start by creating a new working directory and initializing your CLI session.

<pre>
  <code className="language-bash">
    {`mkdir my_project`}
    <br/>
    {`cd my_project`}
    <br/>
    {`${config.cliCommand} login demo.${config.cliCommand}.ai`}
    <br/>
    {`${config.cliCommand} project use sales`}
  </code>
</pre>

## Step 2: Prepare Compute

List available compute instances or create a new one:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute list`}
    <br/>
    {`${config.cliCommand} compute create groot`}
  </code>
</pre>

## Step 3: Create Agent

Create a new agent and associate it with the instance:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} agent create --agent my-agent --instance groot --type REGULAR`}
  </code>
</pre>

List agents to confirm:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} agent list`}
  </code>
</pre>

## Step 4: Generate and Deploy Agent

Generate the agent project locally:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} generate project my-agent --lang ts --template agent`}
    <br/>
    {`cd my-agent`}
  </code>
</pre>

Deploy the agent to the compute instance:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} agent deploy --agent my-agent --instance groot`}
  </code>
</pre>

## Step 5: Cleanup

Remove the agent and logout:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} agent remove my-agent`}
    <br/>
    {`${config.cliCommand} logout demo.${config.cliCommand}.ai`}
  </code>
</pre>
