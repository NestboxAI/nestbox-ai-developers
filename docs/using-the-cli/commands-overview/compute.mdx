This page describes all commands available in the <SiteName /> CLI for managing compute instances. Compute instances are required to host and run agents. You can list, create, and delete them.

Each compute instance is associated with a specific project and is referenced by its name.

## List Compute Instances

Display all compute instances associated with the current project:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute list`}
  </code>
</pre>

You can optionally specify a different project using the `--project` flag:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute list --project <project-id>`}
  </code>
</pre>

**Options:**
- `--project <projectId>` – Project ID or name (defaults to the current project)

## Create a Compute Instance

Create a new compute instance:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute create <instance-name>`}
  </code>
</pre>

You can also specify a project:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute create <instance-name> --project <project-id>`}
  </code>
</pre>

**Parameters:**
- `<instance-name>` – Name for the new compute instance

**Options:**
- `--project <projectId>` – Project ID or name (defaults to the current project)

## Delete a Compute Instance

Delete a compute instance:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute delete <instance-name>`}
  </code>
</pre>

To skip the confirmation prompt, use the `--force` flag:

<pre>
  <code className="language-bash">
    {`${config.cliCommand} compute delete <instance-name> --force`}
  </code>
</pre>

**Parameters:**
- `<instance-name>` – Name of the compute instance to delete

**Options:**
- `--project <projectId>` – Project ID or name (defaults to the current project)
- `--force` – Skip confirmation prompt
