# Creating a new project

In Nestbox, a Project is an isolated workspace that contains its own team members, resources, compute instances, document storage, AI agents, and workflows.
Each project is completely separate from others, allowing you to manage different initiatives, environments, or clients independently.

## How to create a Project

### 1. Locate the Project Selector

In the top-left corner of the dashboard, you’ll see a dropdown showing the name of your current project.

### 2. Open the Project Menu

Click the dropdown.
At the bottom of the list, select "Add New Project".

### 3. Fill in Project Details

You will be prompted to provide:

-   **Project Name** — A unique name to identify your project.
-   **Project Description** — (Optional) A short description of the project’s purpose or scope.

### 4. Create the Project

Click **Add** to create your new project. Once created, you will automatically switch to the new project workspace.

## What Happens When You Create a New Project

-   A **new team** is initialized specifically for the project (you can invite members separately).
-   You get **isolated storage** for documents, collections, and compute instances.
-   You manage **resources and settings** independently of other projects.
-   Your project will appear in the project selector for easy switching between multiple active projects.
